# Arcane Ascension - releases

Aqui ficam as versoes do jogo **Arcane Ascension** (RPG de acao 3D para magos, feito em Godot).

- **ArcaneAscension_Setup.exe**: instalador para Windows (so na primeira vez).
- O jogo instalado procura sozinho novas versoes aqui e se atualiza (baixa so o ArcaneAscension.pck, ~1 MB).

Veja a aba **Releases** para baixar.
